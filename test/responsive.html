Responsive sweep

Loads every example at each width from 320px to 1440px in 20px steps and measures every div's getBoundingClientRect() against the viewport edge. This cannot be done in Node — it needs real layout. It also cannot be done with scrollWidth: the exported reset sets overflow-x: hidden on body, so an overflowing element produces no scrollbar and the page looks clean while content is silently clipped.
